# Opis elementów

**setContentView** –ustawia jaki layout ma być pokazany na ekranie

**findViewById** –znajduje element z XML po jego id żeby móc nim sterować z Javy

**R** –automatycznie generowana klasa która zawiera identyfikatory wszystkich zasobów

**onCreate** –metoda wywoływana przez system przy tworzeniu ekranu

**super.onCreate** –wywołuje wersje metody z klasy nadrzędnej (musi być)

**AndroidManifest.xml** –plik w którym Android czyta informacje o aplikacji (nazwa, ikona, ekrany)

**@+id/** – to tworzy nowy identyfikator elementu w XML

**match_parent** –element zajmuje całą dostępną szerokość/wysokość rodzica czyli elementu w ktorym jest

**dp** –jednostka niezależna od gęstości ekranu (do rozmiarów)

**sp** – jednostka tekstowa która skaluje się z czcionka
